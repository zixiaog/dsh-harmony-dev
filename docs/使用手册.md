# 使用手册 · 鸿蒙开发台（harmony-dev-kit）

> 版本：M5 / 内容 366 条 · 5 个工具 · 官方知识库通道 · 面板五 Tab
> 读者：把插件装进 DeepSeek Harness 后使用的开发者

---

## 1. 它是什么

一个装进 Harness 的鸿蒙原生开发助手，提供四件事：

| 你要的 | 它给的 |
|---|---|
| 查规范 | 60 条设计规范条目（色彩/字体/间距/圆角/动效/布局/无障碍/UX 标准） |
| 查组件 | 40 张组件卡（属性/事件/示例/坑/适配，含版本过滤） |
| 查 API | 200 条 API 卡（网络/数据/权限/媒体/Web/分布式…）+ 40 张 Kit 概览 |
| 学 | 46 讲课程 + 20 个可读示例 |
| 写代码 | `harmony_build` 生成 tokens/工程骨架/页面，自带规范自查 |
| 查问题 | `harmony_check` 六种校验（review/migrate/a11y/one_multi/version/release） |
| 查官方原文 | 华为知识库 MCP 通道（`searchDocuments` / `getDocumentsById`），失败自动降级本地快照 |

---

## 2. 安装与回退

安装（需审批，影响整个 profile）：

```
plugin_manager install_bundle  target = <workspace>/harmony-dev-kit
```

- 新装热生效；替换同名包需重启或 `set_bundle` 开关一次。
- **不要手抄进 `node_modules`**（会被 pnpm 清掉）。
- 回退：`plugin_manager remove_bundle target=dsh-harmony-dev`；或 `set_bundle enabled=false` 先禁用排查。

## 3. 四个工具怎么用

### 3.1 `harmony_search` —— 统一检索

```json
{ "query": "列表 滑动删除", "domain": "component", "limit": 5, "targetApi": "6.1.1(24)" }
```

返回：`data.cards[]`（本地卡片）、`data.rules[]`（相关规则）、`data.tokens[]`（token 命中）、`data.official.docs[]`（官方文档片段）、`citations[]`、`warnings[]`。

- `domain`：`component` / `design` / `api` / `engineering` / `tutorial`。
- `targetApi`：低于该基线的卡片会被过滤并给出排除警告（默认 `6.1.1(24)`）。
- 官方通道不可用时 `warnings` 会写「已降级到本地快照」。

### 3.2 `harmony_get` —— 取完整条目

```json
{ "ref": "comp.list" }          // 组件卡
{ "ref": "R003" }               // 规则
{ "ref": "Title_L" }            // token
{ "ref": "versions" }           // 版本表
{ "ref": "24→26", "kind": "version" }   // 版本差异
{ "ref": "doc:alliance/document/cn/harmonyos-references/ts-container-listitem", "kind": "official" } // 官方全文
```

### 3.3 `harmony_build` —— 生成代码

```json
{ "action": "tokens" }
{ "action": "scaffold", "name": "Demo" }
{ "action": "page", "name": "SettingsPage", "layout": "settings" }
```

返回 `data.files[]` 与 `data.selfCheck`（魔法值 0 / 断点 / 无障碍 / 状态管理 V2）。`selfCheck.pass=false` 时按 `violations` 修。

### 3.4 `harmony_check` —— 校验代码

```json
{ "action": "review", "code": "<ArkTS 源码>" }
{ "action": "review", "path": "entry/src/main/ets/pages/Index.ets" }
{ "action": "migrate", "code": "<V1 代码>" }
{ "action": "a11y", "code": "..." }
{ "action": "one_multi", "code": "..." }
{ "action": "version", "from": "6.1.1(24)", "to": "26.0.0" }
{ "action": "release" }
```

`review` 返回 `diagnostics[]`（ruleId / severity / line / message / fix / url）与 `summary.verdict`（`blocked` / `pass_with_warnings` / `pass`）。

### 3.5 `harmony_create` —— 直接生成工程

```json
{ "name": "DemoApp", "template": "tabs" }
{ "name": "DemoApp", "path": "F:\\projects\\DemoApp", "template": "list", "targetApi": "6.1.1(24)" }
```

- 参数：`name`（必填）、`path`（默认 `<当前目录>/harmony-projects/<name>`）、`template`（`empty`/`tabs`/`list`/`settings`）、`bundleName`、`targetApi`、`force`（目标非空时覆盖）
- 生成 20 个文件：`AppScope/`、`build-profile.json5`、`hvigorfile.ts`、`oh-package.json5`、`hvigor/`、`.gitignore`、`entry/`（module.json5、EntryAbility、Index.ets、Tokens.ets、资源与 profile）
- 打开方式：DevEco Studio → Open 该目录 → hvigor Sync → 配置自动签名 → 运行
- 边界：**不编译、不签名、不上架**；首次 Sync 需要联网装依赖

## 4. 面板

左栏「鸿蒙开发台」图标 → 整页面板，五个 Tab：

| Tab | 内容 |
|---|---|
| 设计 token | 色彩（浅/深）、字号阶梯、多设备边距、圆角、动效、断点栅格 |
| 规则 | 34 条规则（L1 静态 / L2 树 / L3 像素），按严重度标记 |
| 内容库 | 三级目录：官方一级（应用框架 / 系统 / 媒体 / 图形 / 应用服务 / AI / UX 设计规范 / 教程 / 标准库）→ 二级分组（系统下分 安全/网络/基础功能/硬件；应用框架分 ArkUI/ArkTS/ArkWeb/数据管理/基础能力…）→ Kit 或组件类别；右侧分组标题可点击折叠；每张卡都有「主题（N）」可下钻（正文 + 代码 + 官方原文链接）。主题来源：精编（List/Grid/WaterFlow/UI Design Kit）、官方目录（Kit 卡从官方简介页解析子章节）、自动整理（属性/事件/坑等已核实字段） |
| 示例 | 20 个可读示例的标题与文件路径 |
| 版本 | 版本口径、14 个版本对照、apiDiff 摘要 |

顶部「基线」按钮可循环切换 `6.1.1(24)` / `6.1.0(23)` / `6.0.0(20)` / 全部——内容库会按 `since` 过滤，并显示被排除条目；左侧分类与顶部搜索可叠加使用。

## 5. 官方通道与降级

- 首次查询会 `initialize` 再检索，可能耗时数秒；默认超时 **12s**，失败熔断 **60s**。
- 熔断期间 `warnings` 提示「使用本地快照」，其余照常返回。
- 想强制离线：在插件配置行写 `config: { mcp: false }`（配置为 JSON Schema 校验限制，当前版本用默认值；M4 后支持 zod Config）。

## 6. 常见问题

| 现象 | 处理 |
|---|---|
| 工具表没有 `harmony_*` | 确认 bundle 已 enable；看 `%DSH_HOME%/harmony-dev-kit/plugin.log` 是否有 `apply called` |
| 改了数据但结果没变 | toggle 只重载代码模块；改 `index.js` 版本注释再 toggle，或重启 |
| 面板图标不出现 | 刷新页面；确认 `sidebar.panellist` 有 occupant |
| 官方通道一直降级 | 检查网络/代理；端点 `connect-api.cloud.huawei.com/api/developerknowledge/mcp` |

---

## 7. 隐私

插件只读本地内容与用户显式传入的代码；开启官方通道时会把**查询词**发给华为文档检索服务，不发送代码与用户数据。关闭方式见 §5。
